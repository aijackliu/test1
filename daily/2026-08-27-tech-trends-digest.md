[Trend 3] AI agent security is moving from theory to containment engineering.
Trail of Bits’ write-up arguing that VMs no longer safely contain cyber-capable agents landed on Hacker News fast, and the post is notable because it frames advanced agents as something closer to an APT than a mere coding assistant. That changes the security conversation from prompt safety to execution boundaries, host isolation, and whether traditional sandbox assumptions are already obsolete.
References: https://blog.trailofbits.com/2026/08/26/vms-wont-contain-cyber-capable-agents/ | https://news.ycombinator.com/item?id=49450188 | https://www.youtube.com/watch?v=4wMRXmLpdA8

[Trend 4] Open-source data infrastructure is getting pulled deeper into hyperscaler gravity.
DuckLabs’ announcement that it is joining AWS is a big moment because DuckDB has become one of the default tools in modern analytics workflows, yet the team is explicitly promising that DuckDB and the broader Duck Stack remain MIT-licensed and foundation-governed. The core signal is that hyperscalers still want to own the distribution and support layer around developer-loved open infrastructure, even when the underlying project stays open.
